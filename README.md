Entry for the make.fun bounty **One-Line Roast: The Gadget You Use Every Day** — one original line, at most 200 characters, roasting the gadget I use every day.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-gadget-out node main.ts
```

This writes the roast line to `entry.txt` inside the output directory (default `/output`).

## Entry

> My phone hits 1% at 4pm every day, then stays on 1% for three hours — it's not dying, it's holding my evening hostage until I admit I have a problem.
